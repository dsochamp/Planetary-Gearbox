# Planetary Gearbox

I wanted to get into creating functional 3D printable parts using my CAD skills so I created a Planetary Gearbox with functioning parts as a showpiece. It includes the Sun, the Moon, the Earth (with its tilt axis being 23.5 degrees to match how the Earth is tilted in real-life). It features moving parts with a cool ribbed design and stars on the base to give it the planetary feel.

## Tech-Stack

This was a fairly simple project including Onshape for the 3D modelling and Git to push changes through the terminal to the repository. You can also have a look at my project's page on Printables here: [https://www.printables.com/model/1858644-planetary-gearbox](https://www.printables.com/model/1858644-planetary-gearbox)

## Construction

I highly suggest using a dissolvable filament for the gears as they have tight tolerances so use dual filament, with dissolvable filament as the support structures so you don't have to dig in to tight places. I also suggest printing this with PETG which is a bit stronger and also to sand down the gears before use just to make the gears smoother especially the parts that rotate and slide past each other. Assembly should involve just sticking them together, with the base going first and building on top of that.
